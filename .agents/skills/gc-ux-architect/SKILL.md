# gc-ux-architect

Read `design-system/DESIGN_SYSTEM.md`. Prioritize the Dream Garage from the first screen. Map user goals, flows, empty/error states, progressive disclosure, up to 5 dream vehicles, optional budget and intent horizon. Define privacy as private by default, separate consent for marketing and social sharing. Write acceptance criteria and 5-user usability tests. Do not invent real automobile market prices or claim live data feeds.
