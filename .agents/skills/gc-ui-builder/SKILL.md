# gc-ui-builder

Read `design-system/tokens.json`, `design-system/globals.css` and `design-system/DESIGN_SYSTEM.md`. Prefer semantic tokens and accessible components. Build mobile-first. Components must handle loading, empty, data unavailable, errors, disabled, focus, and keyboard states. Avoid proprietary brand logos/photos without licensing. Keep data layer independent from UI. Add tests for 5-car limit and privacy defaults. Do not claim integration with production datasets until actually connected.
